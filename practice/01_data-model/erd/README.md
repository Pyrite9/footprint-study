## ERD 캔버스 보는 방법

1. 아래 주소를 Chrome이나 Edge로 열 것
   - https://pyrite9.github.io/footprint-study/practice/01_data-model/erd/erd_canvas.html
   - 열리지 않으면 `erd_canvas.html`을 내려받아 브라우저로 열 것. GitHub 웹에서는 HTML 코드만 보임. 파일을 연 뒤 오른쪽 위의 내려받기 버튼(Download raw file)을 누름
   - 인터넷이 없어도 열림. 글꼴만 인터넷에서 받아오고, 없으면 맑은 고딕으로 보임
2. 화면 사용법
   - 끌어서 이동하고, 마우스 휠로 확대함
   - 테이블을 누르면 그 테이블이 화면에 맞게 커지고, 오른쪽에 설명이 열림
   - 설명에는 테이블의 용도와 연결된 테이블, 그 테이블의 담당이 나옴
   - 왼쪽 패널 맨 위의 "담당"에서 이름 옆의 테이블을 누르면 그 테이블로 이동함
   - 위쪽의 "물리"와 "논리" 버튼으로 두 모델을 바꿔 봄
   - Esc를 누르면 설명이 닫힘
3. 발표 순서
   - 위쪽의 "발표 순서" 버튼을 누르면 10단계로 설계를 설명함. 단계마다 발표할 사람의 이름이 나옴
   - 오른쪽 화살표나 스페이스로 다음, 왼쪽 화살표로 이전, Esc로 끝냄

## 읽는 법

- 단계: 외래 키가 없는 테이블이 0단계임. 나머지는 가리키는 테이블 중 가장 깊은 단계에 1을 더함
- 물리 화면의 선은 외래 키 컬럼에서 나와, 가리키는 테이블의 기본 키 컬럼(`약어_id`)으로 들어감
- 선 색은 어느 테이블의 기본 키를 가리키는지에 따라 다름
- 키 이름: 기본 키는 `약어_id`(예: `mbr_id`), 외래 키는 가리키는 테이블의 기본 키 이름을 그대로 씀. 역할이 있으면 역할 약어를 앞에 붙임(예: `prof_mbr_id`는 과제를 만든 교수 회원)
- 약어 범례에서 테이블 약어를 누르면 그 테이블로 이동함

## PDF 다시 만들기

- 필요한 것: Python 3, `pip install playwright`, `playwright install chromium`, Noto Sans CJK KR, Noto Serif CJK KR 글꼴
- 업무 데이터 대응: `python3 build_pdf.py 업무데이터대응_원고_v2.md 업무데이터대응_v2.pdf`
- 발표 순서: `python3 build_pdf.py ERD발표순서_원고_v1.md ERD발표순서_v1.pdf --h3-page` (단계마다 새 쪽에서 시작)
- 원고 맨 위의 `> 항목: 내용` 줄이 요약 상자가 됨

## 물리 ERD 그림 다시 만들기

- 필요한 것: Python 3, Graphviz(`dot`), Noto Sans CJK KR 글꼴
- 이 폴더에서 `python3 gen_fig.py erd_canvas.html .`
- 캔버스의 데이터에서 키 컬럼만 뽑아 그림. 2026.12.11 학기 발표 흐름에 쓰는 테이블은 머리를 채움
