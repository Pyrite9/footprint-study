# 발자국 데이터 모델 초안

- 여러분이 제출한 데이터 모델을 모아 전체 서비스의 데이터 모델로 만든 초안임
- 테이블은 12개임. 아직 확정이 아니며 바뀔 수 있음
- 의견은 이 폴더의 PR 댓글이나 단체방에 남길 것

## 파일

| 파일 | 내용 |
|---|---|
| `erd_canvas.html` | ERD 캔버스. 브라우저에서 여는 화면 |
| `데이터모델_보고서원고_v4.md` | 보고서 원고. 용어 사전, 정의서, 제약, 인덱스 |
| `erd_logical_1.png`, `erd_logical_2.png` | 논리 ERD 그림. 원고에 들어감 |
| `erd_physical_1.png`, `erd_physical_2.png` | 물리 ERD 그림. 원고에 들어감 |
| `schema.sql` | PostgreSQL에서 테이블을 만드는 SQL |
| `업무데이터대응_v1.pdf` | 단위 업무와 데이터 대응. 업무마다 어떤 테이블을 만들고, 읽고, 바꾸는지 정리함 |
| `업무데이터대응_원고_v1.md` | 위 PDF의 원고 |

## ERD 캔버스 보는 방법

1. 아래 주소를 Chrome이나 Edge로 열 것
   - https://pyrite9.github.io/footprint-study/practice/01_data-model/erd/erd_canvas.html
   - 열리지 않으면 `erd_canvas.html`을 내려받아 브라우저로 열 것. GitHub 웹에서는 HTML 코드만 보임. 파일을 연 뒤 오른쪽 위의 내려받기 버튼(Download raw file)을 누름
   - 인터넷이 없어도 열림. 글꼴만 인터넷에서 받아오고, 없으면 맑은 고딕으로 보임
2. 화면 사용법
   - 끌어서 이동하고, 마우스 휠로 확대함
   - 테이블을 누르면 그 테이블이 화면에 맞게 커지고, 오른쪽에 설명이 열림
   - 설명에는 테이블의 용도와 연결된 테이블이 나옴
   - 위쪽의 "물리"와 "논리" 버튼으로 두 모델을 바꿔 봄
   - Esc를 누르면 설명이 닫힘
3. 발표 순서
   - 위쪽의 "발표 순서" 버튼을 누르면 10단계로 설계를 설명함
   - 오른쪽 화살표나 스페이스로 다음, 왼쪽 화살표로 이전, Esc로 끝냄

## 읽는 법

- 단계: 외래 키가 없는 테이블이 0단계임. 나머지는 가리키는 테이블 중 가장 깊은 단계에 1을 더함
- 물리 화면의 선은 외래 키 컬럼에서 나와, 가리키는 테이블의 `id` 컬럼으로 들어감
- 선 색은 어느 테이블의 `id`를 가리키는지에 따라 다름
