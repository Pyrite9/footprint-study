# 발자국 학습 계획 2단계 — 팀 조장 (10.16 ~ 11.15)

이 문서는 팀 조장의 할 일입니다. 조원도 볼 수 있습니다. 조원의 6주차부터 8주차까지가 팀 조장의 일정에 달려 있기 때문입니다. 일정이 밀리면 이 문서에서 먼저 보입니다.

팀 조장의 5주차는 1단계 마감일인 10.16(금)에 시작합니다.

2단계에서 팀 조장은 세 가지를 합니다.

- API 명세와 골격을 만들어 조원이 담당 기능만 채우게 합니다.
- 12.11 흐름 전체가 동작하는 시연본을 AI 도구로 만듭니다. 12.15 결과물 제출의 대비이자 11.16 이후 통합의 기준입니다.
- 골격과 시연본의 코드를 모두 읽고 설명할 수 있게 됩니다. 조원의 질문과 발표 질의응답에 답하기 위해서입니다.

분량은 팀 조장이 정한 작업 시간 상한 안에서 잡았습니다. 아래 "미룰 수 없는 것"이 하루라도 밀리면, 그 주의 "밀리면 뒤로 보내는 순서"를 바로 적용합니다.

## 미룰 수 없는 것 3개

1. **10.22(목) API 명세 공개.** 조원 5명의 6주차가 여기에 달려 있습니다.
2. **10.25(일) 골격 공개.** 조원 5명의 6주차가 여기에 달려 있습니다.
3. **11.14(토) 시연본으로 12.11 흐름 전체가 동작.** 12.15 결과물 제출의 대비입니다.

## 시연본을 만드는 규칙

- 시연본은 본 저장소(`footprint`, 비공개)에 둡니다. 11.15까지 조원에게 공개하지 않습니다. 학습용 저장소에는 올리지 않습니다.
- 시연본은 API 명세와 골격을 그대로 따릅니다. 파일 이름도 조원과 같게 씁니다. 그래야 11.16부터 조원의 파일이 시연본의 같은 파일을 대체할 수 있습니다.
- AI 도구가 지킬 규칙은 `CLAUDE.md`에 적습니다. 내용은 `docs/decisions.md`의 결정과 같습니다. 추가로 다음을 금지합니다. MapStruct, QueryDSL, 상속으로 만드는 공통 부모 클래스, 공통 응답 감싸기 클래스, 상태 관리 라이브러리입니다. 조원이 복사해서 읽을 코드이기 때문입니다.
- 하루에 생성한 코드는 그날 안에 읽습니다. 설명하지 못하는 줄은 다음 날 생성을 시작하기 전에 고치거나 지웁니다. 생성한 코드의 양보다, 읽고 이해한 코드의 양을 기준으로 삼습니다.
- 확인 방법: 그날 생성한 파일 중 1개를 골라, 주석을 보지 않고 소리 내어 설명해 봅니다.
