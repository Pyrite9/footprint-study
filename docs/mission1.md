## 2. 준비 (전원 같음)

### 2-1. Node.js 버전 확인

1. VS Code를 엽니다.
2. 위쪽 메뉴에서 [터미널] → [새 터미널]을 누릅니다. 아래쪽에 터미널이 열립니다.
3. 아래 명령을 입력하고 Enter를 누릅니다.

```
node -v
```

4. `v24`로 시작하는 숫자가 나오면 됩니다.
   - 숫자가 24보다 작으면 https://nodejs.org 에서 **LTS** 버튼을 눌러 설치합니다. 설치한 뒤 VS Code를 껐다가 다시 켭니다.

### 2-2. 시연본을 내 컴퓨터로 복사하기

1. 터미널에 아래 명령을 입력합니다. 지금 터미널이 있는 폴더에 `footprint-demo` 폴더가 생깁니다.

```
git clone https://github.com/Pyrite9/footprint-demo
```

2. VS Code 위쪽 메뉴에서 [파일] → [폴더 열기]를 누릅니다.
3. 방금 생긴 `footprint-demo` 폴더를 고릅니다.

### 2-3. 가짜 API 켜기

1. [터미널] → [새 터미널]을 누릅니다.
2. 아래 명령을 **한 줄씩** 입력하고 Enter를 누릅니다.

```
cd frontend
npm install
npm run mock
```

3. `http://localhost:3001`이라는 글자가 보이면 성공입니다.
4. **이 터미널은 끄지 않습니다.** 끄면 가짜 API도 꺼집니다.

### 2-4. 화면 켜기

1. 터미널 창 오른쪽 위의 **+** 버튼을 눌러 터미널을 하나 더 엽니다.
2. 아래 명령을 한 줄씩 입력합니다.

```
cd frontend
Set-Content -Path .env.local -Value "VITE_API_URL=http://localhost:3001" -Encoding ascii
npm run dev
```

3. `http://localhost:5173`이라는 글자가 보이면 성공입니다. 이 터미널도 끄지 않습니다.

※ Mac을 쓰는 사람은 두 번째 줄 대신 `echo "VITE_API_URL=http://localhost:3001" > .env.local`을 입력합니다.

### 2-5. 로그인하기

1. 브라우저 주소창에 `http://localhost:5173`을 입력합니다.
2. 로그인 화면 아래의 **"시작 계정으로 로그인 (개발·백업용)"**을 누릅니다.
3. 아래 계정 중 하나로 로그인합니다. 비밀번호는 모두 `pass1234`입니다.

| 이메일 | 이름 | 누구인가 |
|---|---|---|
| professor@example.com | 이교수 | 교수 |
| student01@example.com | 김민준 | 학생 |
| student02@example.com | 이서연 | 학생 |
| student06@example.com | 강지우 | 학생 |

**탭마다 따로 로그인됩니다.** 예를 들어 첫 번째 탭은 교수, 두 번째 탭은 학생으로 동시에 로그인할 수 있습니다. 미션에서 여러 사람 역할을 할 때 이 방법을 씁니다.

### 2-6. 처음 상태로 되돌리기

결과가 이상하거나 처음부터 다시 하고 싶으면 다음을 합니다.

1. 가짜 API를 켠 터미널(2-3)을 누르고 `Ctrl + C`를 눌러 끕니다.
2. 아래 명령을 입력합니다.

```
git restore db.json
npm run mock
```

## 3. 코드에서 찾는 방법 (전원 같음)

미션의 "찾기"는 모두 이 방법으로 합니다.

1. 화면에 나온 문장을 마우스로 끌어서 복사합니다.
2. VS Code에서 `Ctrl + Shift + F`를 누릅니다. 왼쪽에 검색 칸이 열립니다.
3. 복사한 문장을 붙여 넣습니다. 프로젝트 전체에서 그 문장이 들어 있는 곳이 나옵니다.
4. 결과를 누르면 그 파일의 그 줄로 이동합니다. 왼쪽 숫자가 줄 번호입니다.

- 백엔드 담당은 이름이 `.java`로 끝나는 파일을 봅니다.
- 프론트엔드 담당은 `frontend/src` 안의 파일을 봅니다.
- `mock/middleware.cjs`는 가짜 API 파일입니다. 검색 결과에 나와도 답으로 적지 않습니다.

한 파일 안에서만 찾을 때는 그 파일을 열고 `Ctrl + F`를 누릅니다.

## 4. 답을 적는 방법 (전원 같음)

### 4-1. 단계 끝의 표시를 봅니다

질문마다 단계에 번호(1, 2, 3 …)가 있습니다. 어떤 단계는 끝에 표시가 붙어 있습니다. **표시가 붙은 단계만 답을 적습니다.** 표시가 없는 단계는 하기만 하고 적지 않습니다.

| 표시 | 적는 것 |
|---|---|
| **[캡처]** | 화면을 캡처해서 이미지로 붙입니다. |
| **[문장]** | 화면에 나온 문장이나, 화면에서 본 결과를 한 줄로 적습니다. |
| **[코드]** | 찾은 코드를 복사해서 붙입니다. **최대 5줄**입니다. 파일 이름과 줄 번호를 함께 적습니다. 함수 전체를 붙이지 않습니다. |
| **[내 말로]** | 1~2문장으로 적습니다. 코드를 그대로 옮기지 않고, 무슨 뜻인지를 내 말로 적습니다. |

**답의 번호는 단계의 번호와 같게 씁니다.** 예를 들어 4번 단계에 [문장]이 붙어 있으면, 답에도 "4."라고 쓰고 그 문장을 적습니다.

### 이종민 — 과제 만들기 (백엔드)

**이 기능은 무엇인가요:** 교수가 과제를 등록하고, 조마다 조장을 한 명씩 정하는 기능입니다.

**주로 볼 파일:** `backend/src/main/java/com/footprint/backend/service/AssignmentService.java`

#### 질문 1. 교수로 과제 만들기

1. 교수 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 **새 과제**를 누릅니다.
3. 제목, 시작일, 종료일을 넣습니다. 조장 이메일 칸에 `student01@example.com`을 넣습니다.
4. **입력 내용 확인** → **등록**을 누릅니다.
5. 등록한 뒤의 화면을 캡처합니다. **[캡처]**

#### 질문 2. 학생이 과제를 만들면 어떻게 되나요

1. 새 탭을 엽니다. `student01@example.com`으로 로그인합니다.
2. 학생 화면에는 "새 과제" 메뉴가 없습니다. 주소창에 `http://localhost:5173/assignments/new`를 직접 입력합니다.
3. 질문 1과 같은 방법으로 과제를 등록해 봅니다.
4. 화면 위에 빨간 띠로 나온 문장을 적습니다. **[문장]**
5. 그 문장을 `Ctrl + Shift + F`로 찾습니다. `.java` 파일에서 그 문장이 있는 줄과, 바로 위의 `if`로 시작하는 줄까지 붙입니다. **[코드]**
6. 이 `if`가 무엇을 확인하는지 적습니다. **[내 말로]**

#### 질문 3. 같은 학생을 두 조의 조장으로 넣으면 어떻게 되나요

1. 교수 탭으로 돌아가서 **새 과제**를 누릅니다.
2. **+ 조 추가**를 눌러 조를 2개로 만듭니다. 두 칸 모두에 `student01@example.com`을 넣고 등록합니다.
3. 빨간 띠로 나온 문장을 적습니다. **[문장]**
4. 그 문장이 있는 `.java` 코드를 찾아 붙입니다. **[코드]**
5. 왼쪽 메뉴의 **내 과제**를 누릅니다. 방금 등록하려던 과제가 목록에 생겼는지 적습니다. **[문장]**
6. 생겼거나 생기지 않은 이유를 적습니다. **[내 말로]**
   - 힌트: `AssignmentService.java`의 `create` 안에서, 이메일을 검사하는 줄과 저장하는 줄(`save`) 중 어느 것이 먼저 나오는지 봅니다.

### 장호진 — 조 합류와 역할 (백엔드)

**이 기능은 무엇인가요:** 조장이 초대 링크를 만들어 조원을 부릅니다. 조원이 들어오면 조장이 역할을 정해 줍니다.

**주로 볼 파일:** `backend/src/main/java/com/footprint/backend/service/TeamService.java`

**탭 4개를 씁니다.**

| 탭 | 계정 |
|---|---|
| 탭 1 | professor@example.com (교수) |
| 탭 2 | student01@example.com (1조 조장) |
| 탭 3 | student06@example.com (2조 조장) |
| 탭 4 | student02@example.com (합류하는 학생) |

#### 질문 1. 초대 링크로 합류하기

1. 탭 1에서 **새 과제**를 누릅니다. **+ 조 추가**로 조를 2개 만듭니다. 1조 조장은 `student01@example.com`, 2조 조장은 `student06@example.com`으로 넣고 등록합니다.
2. 탭 2에서 **내 과제**에서 탭 1이 방금 만든 과제(탭 1에서 넣은 제목)를 누릅니다. 조 화면으로 이동합니다.
3. **초대 링크** 칸의 버튼을 눌러 링크를 만듭니다. 나온 링크를 복사합니다.
4. 탭 4의 주소창에 그 링크를 붙여 넣고 **합류**를 누릅니다.
5. 탭 2에서 왼쪽 메뉴의 **조원과 역할**을 누릅니다. 이서연이 보이는 화면을 캡처합니다. **[캡처]**

### 김효민 — 조 합류와 역할 (프론트엔드)

### 양원야 — 동료평가 (프론트엔드)

**이 기능은 무엇인가요:** 과제가 끝나면 조원이 서로를 6개 항목으로 평가합니다. 같은 조의 다른 조원 전원을 한 번에 제출합니다. 제출한 평가는 고칠 수 없습니다.

**주로 볼 파일:** `frontend/src/pages/EvaluationPage.jsx`, `frontend/src/constants/peerEvaluation.js`

#### 질문 1. 동료평가 제출하기

1. `student02@example.com`으로 로그인합니다.
2. **내 과제**에서 **"발자국 평가 단계 과제"**를 누릅니다. 조 화면으로 이동합니다.
3. 왼쪽 메뉴에서 **동료평가**를 누릅니다.
4. 평가할 조원이 2명 있습니다. 한 명씩 눌러서 6개 항목의 점수를 모두 고릅니다.
5. **입력 내용 확인** → **전원 제출**을 누릅니다.

3. 제출한 평가를 고칠 수 없게 만든 이유를 적습니다. **[내 말로]**

   - 이미 제출해서 입력 화면이 보이지 않으면, 처음 상태로 되돌린 뒤(2-6) 화면을 새로고침합니다.

5. 문장을 화면 파일 안에 바로 쓰지 않고 다른 파일에 따로 모아 둔 이유를 적습니다. **[내 말로]**
