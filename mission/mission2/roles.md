## 이종민

**백엔드 / 과제**

교수가 과제를 만들고, 회원이 자기 과제를 조회하는 부분입니다.

| 기능 | 이 기능을 쓰는 화면 |
|---|---|
| 과제 만들기 | 과제 생성 |
| 과제 목록과 상세 보기 | 과제 목록, 과제 상세 |

볼 화면은 [데모 README의 "화면별 설명"](https://github.com/Pyrite9/footprint-demo#화면별-설명)에서 3번 내 과제, 4번 새 과제, 5번 조 현황입니다.

맡는 것

- 교수가 과제명, 기간, 조장을 정해서 과제 만들기
- 과제를 만들 때 조와 조장도 같이 만들기
- 내가 볼 수 있는 과제 목록 보기
- 과제 하나와 그 과제의 조 목록 보기

맡지 않는 것

- 조에 조원이 들어오는 것 (장호진)
- 로그인 (김동건)
- 평가 시작 (나중에)

1차 미션 때와 같은 기능입니다.

## 장호진

**백엔드 / 조, 합류, 역할**

학생이 초대 링크로 조에 들어오고, 조장이 역할을 정해 주는 부분입니다.

| 기능 | 이 기능을 쓰는 화면 |
|---|---|
| 초대 코드 발급, 조원 목록, 역할 지정 | 조원과 역할 |
| 합류, 조 정보 | 합류, 조 홈 |

볼 화면은 [데모 README의 "화면별 설명"](https://github.com/Pyrite9/footprint-demo#화면별-설명)에서 7번 조원과 역할, 8번 초대 링크로 합류입니다.

맡는 것

- 조장이 초대 코드를 발급하고 확인하기
- 조원 목록 보기
- 조장이 조원에게 역할 지정하기
- 초대 링크를 연 학생에게 어느 과제의 어느 조인지 알려 주기
- 학생이 그 조에 합류하기
- 조 정보 보기

맡지 않는 것

- 과제를 만들 때 같이 하는, 조를 처음 만드는 것 (이종민)
- 로그인 (김동건)
- 역할 변경과 이력, 조장 교체 (나중에)

1차 미션 때와 같은 기능입니다.

## 윤장현

**프론트엔드 / 과제 화면, 조원과 역할 화면**

| 화면 | 주소 | 이 화면이 쓰는 백엔드 기능 |
|---|---|---|
| 과제 목록 | `/` | 과제 목록 보기 |
| 과제 생성 | `/assignments/new` | 과제 만들기 |
| 과제 상세 | `/assignments/과제 번호` | 과제 상세 보기 |
| 조원과 역할 | `/teams/조 번호/members` | 초대 코드 발급, 조원 목록, 역할 지정 |

볼 화면은 [데모 README의 "화면별 설명"](https://github.com/Pyrite9/footprint-demo#화면별-설명)에서 3번 내 과제, 4번 새 과제, 5번 조 현황, 7번 조원과 역할입니다.

맡는 것

- 내가 볼 수 있는 과제 목록 보여 주기
- 교수가 과제명, 기간, 조장 이메일을 입력해서 과제 만들기
- 과제의 조 목록 보여 주기
- 조원 목록 보여 주기
- 조장이 초대 링크를 발급하고 복사하기
- 조장이 조원에게 역할 지정하기

맡지 않는 것

- 초대 링크를 연 뒤의 합류 화면 (김효민)
- 로그인 화면과 왼쪽 메뉴 (김동건)
- 평가 시작 버튼, 역할 변경과 이력, 조장 교체 (나중에)

과제 화면은 1차 미션 때 그대로이고, 조원과 역할 화면이 새로 추가됐습니다.

## 김효민

**프론트엔드 / 합류 화면, 조 홈, 산출물 화면**

| 화면 | 주소 | 이 화면이 쓰는 백엔드 기능 |
|---|---|---|
| 합류 | `/join/초대 코드` | 합류 |
| 조 홈 | `/teams/조 번호` | 조 정보, 조원 목록 |
| 산출물 | `/teams/조 번호/deliverables` | 산출물 올리기, 목록, 내려받기 |

볼 화면은 [데모 README의 "화면별 설명"](https://github.com/Pyrite9/footprint-demo#화면별-설명)에서 6번 조 홈, 8번 초대 링크로 합류, 10번 산출물, 11번 산출물 상세입니다.

맡는 것

- 초대 링크를 연 학생에게 어느 조인지 보여 주고, 버튼을 누르면 합류시키기
- 조 홈에서 지금 할 수 있는 일과 최근 산출물 보여 주기
- 산출물 목록 보여 주기
- 파일 올리기
- 파일 내려받기

맡지 않는 것

- 초대 링크를 발급하는 화면 (윤장현)
- 로그인 화면과 왼쪽 메뉴 (김동건)
- 산출물 삭제, 완료확인 (나중에)

합류 화면과 조 홈은 1차 미션 때 그대로이고, 조원과 역할 화면은 윤장현에게 넘기고 산출물 화면을 새로 맡습니다.
조사는 합류, 조 홈, 산출물 순서로 하면 편합니다.

## 양원야

**프론트엔드 / 동료평가 화면, 근거 패널**

| 화면 | 주소 | 이 화면이 쓰는 백엔드 기능 |
|---|---|---|
| 동료평가 | `/teams/조 번호/evaluation` | 동료평가 저장, 근거 기록 조회 |

볼 화면은 [데모 README의 "화면별 설명"](https://github.com/Pyrite9/footprint-demo#화면별-설명)에서 15번 동료평가와 근거 패널입니다.

맡는 것

- 평가할 조원 고르기
- 조원마다 6개 항목의 점수와 의견 입력하기
- 항목마다 점수 기준 문장 보여 주기
- 입력한 내용을 확인 화면에서 한 번에 보고 제출하기
- 오른쪽 근거 패널에서 지금 평가하는 조원의 기록 보여 주기

맡지 않는 것

- 로그인 화면과 왼쪽 메뉴 (김동건)
- 임시 저장 (나중에)
- 교수가 평가 결과를 보는 화면, 기여 항목 화면 (나중에)

1차 미션 때와 같은 기능이고, 근거 패널이 추가됐습니다.
