## 조사서 적는 방법

조사서에는 맡은 기능이 두 부분으로 나뉘어 있어서, 부분마다 1번부터 4번을 채우고 5번은 맨 아래에 한 번만 적으면 됩니다.

칸마다 한두 줄이면 충분하고, 찾지 못한 칸에는 "모르겠음"이라고 적어 주세요.

### 백엔드

| 번호 | 항목 | 적는 것 | 찾는 방법 |
|---|---|---|---|
| 1 | 흐름 | 사용자가 누르고 입력하는 순서 | 데모 README의 화면 사진을 보면서 내가 이 서비스를 쓴다고 생각하고 순서대로 적습니다 |
| 2 | 데이터 | 저장하고 읽는 테이블과 값 | [ERD 캔버스](https://pyrite9.github.io/footprint-study/practice/01_data-model/erd/erd_canvas.html)에서 내 기능의 테이블을 찾습니다 |
| 3 | 주고받는 것 | 만들 API, 받는 값, 돌려주는 값, 지금 만들 수 있는지 | 1번 흐름의 줄마다 화면이 서버에 무엇을 보내고 무엇을 받아야 하는지 생각해서 적고, 주소는 정확하지 않아도 됩니다 |
| 4 | 막아야 하는 경우 | 하면 안 되는 사람이 요청했을 때와 틀린 값이 왔을 때 어떻게 되어야 하는지 | 1번 흐름의 줄마다 "이 사람이 하면 안 되는 경우"와 "값이 틀린 경우"를 하나씩 떠올려 봅니다 |
| 5 | 배워야 하는 것 | 3번에서 "없음"이나 "모르겠음"이라고 적은 API를 만들려면 배워야 하는 것 | 검색하거나 AI에게 물어서 찾고, 찾아본 자료의 주소를 함께 적습니다 |

### 프론트엔드

| 번호 | 항목 | 적는 것 | 찾는 방법 |
|---|---|---|---|
| 1 | 흐름 | 사용자가 누르고 입력하는 순서 | 데모 README의 화면 사진을 보면서 내가 이 서비스를 쓴다고 생각하고 순서대로 적습니다 |
| 2 | 데이터 | 화면이 기억할 값과 서버에서 받을 값 | 화면 사진에 무엇이 보이고 무엇을 입력하는지 보고 적습니다 |
| 3 | 주고받는 것 | 부를 API, 부르는 때, 지금 만들 수 있는지 | 1번 흐름의 줄마다 서버에 무엇을 보내고 무엇을 받아야 하는지 생각해서 적고, 주소는 정확하지 않아도 됩니다 |
| 4 | 막아야 하는 경우 | 하면 안 되는 사람이 눌렀을 때와 틀린 값을 넣었을 때 어떻게 되어야 하는지 | 1번 흐름의 줄마다 "이 사람이 하면 안 되는 경우"와 "값이 틀린 경우"를 하나씩 떠올려 봅니다 |
| 5 | 배워야 하는 것 | 3번에서 "없음"이나 "모르겠음"이라고 적은 것을 만들려면 배워야 하는 것 | 검색하거나 AI에게 물어서 찾고, 찾아본 자료의 주소를 함께 적습니다 |

3번의 "지금 만들 수 있는지"에는 "있음", "없음", "모르겠음" 중 하나를 적습니다.

## 예시

예시로 도서관에서 책을 빌리는 것으로 적어보았습니다.

**1. 흐름**

1. 책 목록에서 책을 고른다
2. "빌리기" 버튼을 누른다
3. 내가 빌린 책 목록에 그 책이 보인다

**2. 데이터 (백엔드)**

| 테이블 | 저장하는 값 | 읽는 값 |
|---|---|---|
| `loan` | `book_id`, `member_id`, `loaned_at` | |
| `book` | | `id`, `title` |

**2. 데이터 (프론트엔드)**

| 화면이 기억할 값 | 서버에서 받을 값 |
|---|---|
| 고른 책의 번호 | 책 목록, 내가 빌린 책 목록 |

**3. 주고받는 것 (백엔드)**

| API | 받는 값 | 돌려주는 값 | 지금 만들 수 있는지 |
|---|---|---|---|
| `POST /loans` | 책 번호 | 대출 기록 | 없음 |
| `GET /loans` | 없음 | 내가 빌린 책 목록 | 있음 |

**3. 주고받는 것 (프론트엔드)**

| 언제 | API | 지금 만들 수 있는지 |
|---|---|---|
| "빌리기" 버튼을 누를 때 | `POST /loans` | 없음 |
| 화면을 열 때 | `GET /loans` | 있음 |

**4. 막아야 하는 경우**

| 어떤 경우 | 어떻게 되어야 하는지 |
|---|---|
| 이미 다른 사람이 빌린 책을 빌리려 할 때 | 빌릴 수 없다고 알려 준다 |
| 로그인하지 않은 사람이 요청할 때 | 거절한다 |
| 없는 책 번호를 보낼 때 | 책이 없다고 알려 준다 |

**5. 배워야 하는 것**

| 3번에서 고른 것 | 배워야 하는 것 | 찾아본 자료 |
|---|---|---|
| `POST /loans` | 로그인한 사람이 누구인지 서버가 아는 방법 | (주소) |
| `POST /loans` | 버튼을 누른 뒤 목록을 다시 그리는 방법 | 모르겠음 |
