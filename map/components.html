발자국 컴포넌트 지도

지금 개발은 발자국 화면 지도의 주차 로드맵을 따릅니다. 이 페이지는 데모의 전체 구조를 보는 참고용입니다. 여기의 번호와 만드는 방법은 따르지 않습니다.
데모의 화면을 실제로 그려지는 순서대로 트리로 펼치고 담당자 색으로 칠했습니다. 번호는 백지에서 처음부터 만들 때의 순서입니다. 내 이름을 누르면 내 파일만 남고, 박스를 누르면 만들 파일과 바꿀 줄이 나옵니다.

3차 미션 때의 만드는 방법 (지금은 쓰지 않습니다)

1. 같은 이름으로 만들기. 원본을 열어 보고 mine 폴더에 같은 이름, 같은 props로 직접 타이핑합니다. 원본 import 경로가 ../나 ./로 시작하면 폴더가 한 칸 깊어진 만큼 ../를 하나 더 붙입니다.

2. import 한 줄 바꾸기. 패널의 "바꿀 줄"에 적힌 파일에서 그 줄의 경로만 mine으로 바꿉니다. 쓰는 곳이 여러 곳이면 모두 바꿔야 모든 화면에 반영됩니다.

3. 화면 비교하기. 바꾸기 전과 후의 화면이 똑같으면 통과입니다. 서버 파일은 아직 바꿔 끼우는 방식이 없어서 본인 Spring Boot 프로젝트에 같은 이름으로 만듭니다.

footprint-demo 커밋 2d40f7b(2026.11.25) 기준. 담당은 2차 미션 역할 배정에 2026.11.26 추가 배정을 더한 것이고, 상태는 3차 미션 제출 기준입니다. 개발 순서는 위에서 아래로(부모를 먼저 만들고 자식 자리는 비워 둠) 만들고, 단계는 개요서의 구현 순서(인증·과제·역할 → 산출물 → 동료평가 → 기여 항목·완료확인 → 근거 패널·교수 열람 → 진척)를 따릅니다.
