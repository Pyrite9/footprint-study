# 구현 조사서 - 김효민

- 맡은 것: 합류 화면, 조 홈, 산출물 화면 (프론트엔드)
- 범위: [역할 카드](../../mission/mission2/roles.md#김효민)
- 적는 방법과 예시: [2차 미션 안내](../../mission/mission2/README.md)

찾지 못한 칸에는 "모르겠음"이라고 적고, 시간이 부족하면 첫 번째 부분만 채워서 내도 됩니다.
3번의 "지금 만들 수 있는지"에는 "있음", "없음", "모르겠음" 중 하나를 적습니다.

## 합류 화면과 조 홈

### 1. 흐름

1. 조장이 좌측하단에 "조원과 역할" 버튼을 누릅니다.
2. 화면에 나오는 초대링크를 복사하여 조원에게 보냅니다.
3. 조원이 초대링크를 누르고 로그인하여 "합류" 버튼을 누릅니다.
4. 조 홈 에서 내가 할수 있는 일을 확인합니다.


### 2. 데이터

| 화면이 기억할 값 | 서버에서 받을 값 |
|---|---|
| 초대 링크 | 초대 링크 정보 |
| 합류 확인 화면의 표시 정보 | 과제 이름 |
| 선택한 조 | 조 이름, 조 아이디 |
| 로그인한 사용자 정보 | 조원 목록 및 역할 정보 |


### 3. 주고받는 것

| 언제 | API | 지금 만들 수 있는지 |
|---|---|---|
| 초대 링크 접속 시 | 초대 링크 정보 조회 API | 모르겠음 |
| 합류 버튼을 눌렀을 때 | 조 합류 API | 모르겠음 |
| 조 홈에 진입했을 때 | 조 정보 및 조원 목록 조회 API | 모르겠음 |


### 4. 막아야 하는 경우

| 어떤 경우 | 어떻게 되어야 하는지 |
|---|---|
| 로그인하지 않은 사용자가 초대 링크에 접속하는 경우 | 로그인 화면으로 이동시킨다 |
| 다른 조에 이미 소속된 사용자인 경우 | 다른 조에 소속된 경우 합류할 수 없다는 안내를 표시한다.|
| 이미 해당 조에 가입한 사용자인 경우 | 중복 합류를 막고 기존에 소속된 조 화면으로 이동 |

## 산출물 화면

### 1. 흐름

1. 조 홈 에서  "최근산출물"또는 좌측의 "산출물 전체" 
2. 조 홈 에서  "최근산출물"또는 좌측의 "산출물 전체" or 우측 하단의 "산출물" 버튼을 클릭하여 올라온 산출물을 확인합니다.
3. 우측 상단의 "파일 올리기" 버튼을 클릭한 후 중앙의 "파일 고르기" 를 클릭한 후 본인의 파일을 선택한 후 "올리기" 버튼을 클릭합니다.
4. "산출물" 목록에서 다른 조원이 올린 산출물 내역에서 우측의 "내려받기" 버튼을 클릭하면 파일을 내려받을 수 있습니다.


### 2. 데이터

| 화면이 기억할 값 | 서버에서 받을 값 |
|---|---|
| 현재 선택한 산출물 | 산출물 아이디 |
| 파일 업로드 창의 표시 여부 | 파일 이름 |
| 업로드 할 파일 | 파일 크기 |
| 상세 정보 창의 표시 여부 | 파일을 올린 사람 |
| 현재 선택한 파일 | 파일을 올린 시각 |
| 다운로드할 파일 | 파일 다운로드 정보 |


### 3. 주고받는 것

| 언제 | API | 지금 만들 수 있는지 |
|---|---|---|
| 산출물 화면에 진입했을 때 | 산출물 목록 조회 API | 모르겠음 |
| 파일을 올렸을 때 | 산출물 파일 업로드 API | 모르겠음 |
| 파일을 클릭했을 때 | 산출물 상세 정보 조회 API | 모르겠음 |
| 내려받기 버튼을 눌렀을 때 | 산출물 파일 다운로드 API | 모르겠음 |

### 4. 막아야 하는 경우

| 어떤 경우 | 어떻게 되어야 하는지 |
|---|---|
| 파일을 선택하지 않고 올리기를 누른 경우 | 파일을 선택하라는 안내를 표시한다. |
