## 질문 2. 다른 조에 또 합류하면 어떻게 되나요

3. 빨간 띠로 나온 문장 **[문장]**

이미 이 과제의 다른 조에 있습니다

4. 그 문장이 있는 코드 **[코드]**

TeamService.java 
```java
        if (existing.isPresent()) {
            if (existing.get().getTeam().getId().equals(team.getId())) {
                return team;
            }
            throw new DuplicateException("이미 이 과제의 다른 조에 있습니다");
```

5. 1조 링크를 다시 열고 합류를 눌렀을 때 **[문장]**

오류가 나지 않고 그대로 1조 화면으로 들어갑니다.

6. 같은 조는 막지 않고 다른 조는 막는 이유 **[내 말로]**

같은 조에 다시 들어오는 건 새로 저장할 게 없어서 그 조를 되돌립니다. 다른 조에 들어오면 한 과제에 조 참여가 두 개 생기니까 막습니다.

## 질문 3. 역할 이름 앞에 띄어쓰기를 넣으면 어떻게 되나요

2. 저장된 역할 이름 앞에 띄어쓰기가 남아 있는지 **[문장]**

띄어쓰기 없이 "백엔드"로 저장됩니다.

3. assignRole 안에서 띄어쓰기를 지우는 줄 **[코드]**

TeamService.java
```java
        // 앞뒤 공백을 지웁니다. " 백엔드"와 "백엔드"가 다른 역할로 나뉘면 산출물 순번이 끊깁니다.
        target.assignRole(roleName.trim());
```

4. 띄어쓰기를 지우지 않으면 생기는 문제 **[내 말로]**

눈으로는 같은 " 백엔드"와 "백엔드"를 서버는 다른 글자로 봐서 역할이 두 개로 갈립니다. 그러면 같은 역할로 올린 산출물 순번이 중간에 끊깁니다.
