# 구현 조사서 - 윤장현

- 맡은 것: 과제 화면, 조원과 역할 화면 (프론트엔드)
- 범위: [역할 카드](../../mission/mission2/roles.md#윤장현)
- 적는 방법과 예시: [2차 미션 안내](../../mission/mission2/README.md)

찾지 못한 칸에는 "모르겠음"이라고 적고, 시간이 부족하면 첫 번째 부분만 채워서 내도 됩니다.
3번의 "지금 만들 수 있는지"에는 "있음", "없음", "모르겠음" 중 하나를 적습니다.

### 과제화면

#### 1. 흐름

1. '내 과제' 화면에 들어간다.
2. 과제 목록이 보이고, 각 과제에 기록 단계와 평가 단계가 표시되어 있다.
3. 특정 과제를 누르면, 해당 과제의 상세 페이지로 들어간다.

#### 2. 데이터

| 화면이 기억할 값 | 서버에서 받을 값 |
|---|---|
| 선택한 과제 이름 | 내 과제 목록(과제 이름, 기간, 단계) |

#### 3. 주고받는 것

| 언제 | API | 지금 만들 수 있는지 |
|---|---|---|
| '내 과제'를 클릭할 때 | GET /assignments | 모르겠음 |
| 특정 과제를 클릭할 때 | GET /assignments/{특정 과제의 번호} | 모르겠음 |

#### 4. 막아야 하는 경우

| 어떤 경우 | 어떻게 되어야 하는지 |
|---|---|
| 로그인하지 않은 사용자가 과제 목록 화면에 접근을 시도할 때 | 로그인 화면으로 이동시킨다. |
| 존재하지 않는 과제 번호로 상세 페이지 접근을 시도할 때 | 존재하지 않는 과제라고 알려준다. |


## 조원과 역할화면

#### 1. 흐름

1. '조원과 역할 화면'에 들어간다.
2. 조원 목록이 뜨고 조원의 역할이 보인다.
3. 조장인 경우 초대 링크가 보이고 링크를 복사할 수 있다.
4. 조장인 경우 각 조원의 역할을 지정할 수 있다.

#### 2. 데이터

| 화면이 기억할 값 | 서버에서 받을 값 |
|---|---|
| 발급받은 초대 링크 | 초대 링크 |

#### 3. 주고받는 것

| 언제 | API | 지금 만들 수 있는지 |
|---|---|---|
| 조원과 역할 화면을 열 때 | GET /teams/{조 번호} | 모르겠음 |
| 역할 지정 버튼을 누를 때 | POST /teams/{조 번호}/members/{회원 번호}/role | 모르겠음 |
| 초대 발급 버튼을 누를 때 | POST /teams/{조 번호}/invitations | 모르겠음 |

#### 4. 막아야 하는 경우

| 어떤 경우 | 어떻게 되어야 하는지 |
|---|---|
| 로그인하지 않은 사용자가 접근을 시도할 경우 | 로그인 화면으로 이동한다. |
| 존재하지 않는 조 번호로 접근할 때 | 존재하지 않는 조라고 알려준다. |
| 해당 조에 속하지 않는 사람이 접근할 때 | 접근 권한이 없다고 알려주고 거절한다. |


## 5. 배워야 하는 것

| 3번에서 고른 것 | 배워야 하는 것 | 찾아본 자료 |
|---|---|---|
| GET /assignments | 프론트엔드에서 fetch를 사용해 백엔드 서버로부터 과제 목록 데이터를 가져와 화면에 렌더링하는 방법 | https://developer.mozilla.org/ko/docs/Web/API/Fetch_API/Using_Fetch |
| GET /assignments/{특정 과제 번호} | 리액트 등 프론트엔드에서 동적 라우팅(useParams)을 활용해 과제 번호를 추출하고 상세 페이지에 연결하는 방법 | https://velog.io/@nemo/useParams |
| GET /teams/{조 번호} | 프론트엔드에서 useEffect와 fetch를 사용해 컴포넌트가 처음 렌더링될 때 조 정보 데이터를 비동기로 불러오는 방법 | https://velog.io/@juchan1212/Spring-fetch-GET-POST |
| POST /teams/{조 번호}/members/{회원 번호}/role | 프론트엔드에서 버튼 클릭 시 선택한 역할 데이터를 담아 백엔드로 POST 요청을 보내는 방법 | https://developer.mozilla.org/ko/docs/Web/API/Fetch_API/Using_Fetch |
| POST /teams/{조 번호}/invitations | 프론트엔드에서 발급 버튼 클릭 시 서버로 POST 요청을 보내고, 응답으로 받은 초대 링크를 클립보드에 복사하는 방법 | https://developer.mozilla.org/ko/docs/Web/API/Fetch_API/Using_Fetch |
