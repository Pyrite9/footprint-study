## 읽는 순서 (2단계)

2. 본인 역할 문서를 읽습니다.
   - [프론트엔드](docs/01_frontend.md)
   - [백엔드](docs/02_backend.md)
3. [팀 조장](docs/03_leader.md) — 팀 조장의 일정입니다. API 명세와 골격의 공개일이 여기에 있습니다.
4. [결정 기록](docs/decisions.md) — 코드 규칙과 그 이유입니다.
